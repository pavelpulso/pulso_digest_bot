## Лучшие гипотезы (приоритет внедрения)

### Топ-3 «быстрые победы» (низкая сложность + измеримая польза)

1. **Минус-слова** (#15) — сложность 2, потенциал 4. Быстро снижает шум и повышает удовлетворённость без изменения ранжирования.
2. **Приоритет каналов** (#16) — сложность 2, потенциал 4. Минимальные изменения в промпте/логике ранжирования, сильный эффект на релевантность.
3. **Скрыть канал в дайджесте** (#6) — сложность 2, потенциал 4. Простой флаг в БД и фильтр при выдаче; даёт контроль без потери подписки.

### Топ-3 по потенциалу (стратегические)

1. **Push с тизером утром** (#1) — формирует привычку и возврат в продукт; критично для retention.
2. **Оценка поста (лайк/дизлайк)** (#12) — основа для долгосрочной персонализации и улучшения модели.
3. **Рекомендация каналов по профилю** (#4) — рост контента и качества дайджеста; усиливает ценность профиля.

### Рекомендуемый порядок на ближайшие кварталы

- **Сейчас:** #15 (минус-слова), #16 (приоритет каналов), #6 (скрыть канал) — быстрые победы с высокой пользой.
- **Далее:** #9 (время доставки), #2 (напоминание), #14 (личная статистика) — усиление retention и привычки.
- **Потом:** #1 (push с тизером), #12 (лайк/дизлайк), #10 (недельный дайджест) — стратегические шаги по удержанию и персонализации.

## Лучшие из 15 новых гипотез (отбор)

### Топ быстрых побед (низкая сложность + высокая надобность)

1. **«Не присылать в выходные»** (#21) — сложность 1, надобность 4. Одна настройка в БД + проверка дня в cron. Сильно снижает раздражение и отписки.
2. **Оценка дайджеста целиком** (#29) — сложность 2, потенциал и надобность 4. Inline-кнопки после дайджеста, сохранение в БД. Даёт сигнал для улучшения ранжирования без лайков по каждому посту.
3. **Напоминание «не открыли дайджест»** (#30) — сложность 2, потенциал и надобность 4. Cron в 12:00/18:00 + флаг «открывал ли сегодня». Прямой рост метрик открытий.
4. **Не более 1 поста с канала в топ** (#27) — сложность 2, потенциал и надобность 4. Изменение логики выдачи после ранжирования. Улучшает разнообразие без смены модели.
5. **Чёрный список каналов** (#25) — сложность 2, надобность 4. Отдельный флаг «blocked» в настройках канала, фильтр при выдаче. Дополняет «скрыть в дайджесте».

### Топ по стратегическому потенциалу

1. **Плюс-слова** (#34) — сложность 3, потенциал и надобность 5. Дополнение к минус-словам: «показывать посты, где есть X, Y, Z». Сильно повышает ощущение «бот знает, что мне нужно».
2. **Тематические дайджесты** (#26) — сложность 3, потенциал и надобность 4. Разные «режимы» выдачи по темам из профиля. Увеличивает частоту использования и ценность.
3. **Инкрементальный дайджест** (#32) — сложность 3, потенциал и надобность 4. Для power users: «что нового с прошлого раза». Удержание активных пользователей.
